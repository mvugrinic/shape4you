# O aplikaciji

Shape4You je web aplikacija namijenjena korisnicima koji žele jednostavno organizirati i pratiti svoje treninge.

Prilikom prvog korištenja korisnik prolazi kroz onboarding u kojem unosi osnovne podatke, odabire dane treninga i svoje fitness ciljeve. Na temelju tih podataka aplikacija korisniku omogućuje personalizirane treninge.


# Glavne funkcionalnosti aplikacije:

- registracija i prijava korisnika
- onboarding i personalizacija korisničkog profila
- odabir ciljeva i dana treninga
- pregled i izvođenje dnevnih treninga
- Workout Editor za uređivanje treninga
- dodavanje, uređivanje, brisanje i promjenu redoslijeda vježbi
- praćenje težine, BMI-ja i napretka korisnika
- Progress Tracker s tjednim i mjesečnim pregledom
- sustav bodova i streakova
- dnevne izazove
- leaderboard prema bodovima i streaku
- povijest odrađenih treninga
- Spotify integraciju
- spremanje korisničkih podataka i napretka pomoću Firebase/Firestore baze podataka

Aplikacija je izrađena korištenjem Vue.js, Firebase/Firestore i Figma alata za izradu dizajna i prototipa.
